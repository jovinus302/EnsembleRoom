02 · 디자인 토큰

토큰 시트

현재 문제색·radius·글자 크기가 컴포넌트마다 제각각이라 화면 간 일관성이 없다.

이 시안의 해법모든 값을 :root 변수로 일원화했다. 방향 전환은 data-direction 으로 색 토큰만 갈아끼운다.

03 · 컴포넌트 · 패널 · 헤더 · 버튼

패널 틀 · 헤더 · 버튼

현재 문제모든 버튼이 같은 무게라 무엇이 주 행동인지 알 수 없다.

이 시안의 해법CTA 는 아쿠아 40px 하나, 그 외는 32px primary / soft / ghost / destructive 로 위계를 만든다.

이 시안의 해법CTA 는 잉크 pill 40px 하나, 나머지는 바다 틸 primary 와 soft/ghost 로 낮춘다.

04 · 컴포넌트 · 대화 · 3D 말풍선

대화

현재 문제2D 채팅 말풍선과 3D 장면의 Agent 말풍선이 완전히 다른 모양과 색이라 같은 화자로 읽히지 않는다.

이 시안의 해법16px + 발화자 쪽 4px 모서리, 화자 색 tonal 20% 바탕, 같은 태그 규칙을 2D 와 3D 에 똑같이 적용했다.

05 · 컴포넌트 · 승인 카드 (A2H)

승인 카드

현재 문제승인 요청이 일반 카드와 구분되지 않고 승인/거절 색이 화면마다 다르다.

이 시안의 해법노을빛 앰버 #ffb45a 한 가지 띠와 글로우로 주의를 끌고, 승인은 아쿠아 primary 하나로 집중시킨다.

이 시안의 해법앰버 #f59e0b tonal 바탕과 띠로 주의를 끌고, 승인은 바다 틸 primary 하나로 집중시킨다.

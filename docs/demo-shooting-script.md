# Ensemble Room 데모 촬영 대본 (실제 Claude 모드)
마지막 갱신: 흐름 수정 후 실제 Claude 8건 확인 기준


리허설(실제 Claude, 격리 환경)에서 확인한 문장만 본안으로 쓴다. 리허설에서 한 번이라도 어긋난 장면은 "끊어 찍기"로 표시했다.
실제 모델은 같은 문장에도 결과가 달라질 수 있으므로, 각 장면은 **컷을 나눠 찍고 마음에 드는 테이크를 고른다**.

## 1. 사전 준비

1. 실제 Claude 모드로 띄우기: 저장소 루트 `.env`에 `AGENT_MODE=claude`와 접속 정보가 들어 있는 상태에서 `npm run dev`. 기동 후 `GET /api/health`의 `agentMode`가 `claude`인지 확인한다. (키·주소는 대본·화면·녹화에 노출하지 않는다. 터미널 창은 녹화 영역 밖에 둔다.)
2. 대화 기록 초기화: **사용자에게 확인한 뒤에만** 실행한다. 서버를 끄고 `data/`를 지운 뒤 `npm run dev`로 다시 시작한다. 명령(실행하지 않음): `Remove-Item -Recurse -Force data` (PowerShell). 초기화하면 시드(대화, 보드 도구, 일정·취향 기억)가 다시 들어간다.
   - 장면 3~9는 **각 장면 촬영 전에 같은 초기 상태**여야 안정적이다. 이미 한 장면의 대화·승인·도구가 방에 남으면 다음 시도의 모델 응답이 달라진다(리허설에서 확인). 테이크를 다시 찍을 때마다 초기화하거나, 장면별로 방이 다른 점(친구들/가족/팀/My Room)을 이용해 방을 나눠 찍는다.
   - 사다리타기는 한 번 실행하면 결과가 고정된다. 재촬영은 초기화하거나 "다시 하기"를 누른다.
3. 창 2개: 브라우저 창 두 개(또는 한 브라우저의 별도 창)를 **좌=Alice, 우=Bob**으로 로그인한다. 두 창 모두 1920x1080 기준으로 맞추고, 녹화는 창 하나씩 따로(또는 OBS 장면 2개) 잡는다. Bob 창은 평소 **메신저 홈**에 둔다(방에 들어가지 않는다).
4. 해상도·품질: 1920x1080, 3D 품질은 화면 오른쪽 아래 `자동`(문제 있으면 `높음`), 시점은 `시점 초기화`로 시작한다. GPU 가속이 켜진 브라우저(Edge/Chrome)를 쓴다.
5. 온보딩: 처음 로그인하면 가이드가 뜬다. **건너뛰기**를 누른다(메신저 홈, 방 입장 때 각각 한 번씩).
6. 녹화(OBS) 요점: 캔버스 1920x1080 / 30fps(3D 움직임이 많으면 60fps), 화면 캡처(창 캡처가 아닌 디스플레이 캡처 권장), 마우스 커서 표시, 인코더는 하드웨어(NVENC 등) 고품질, 오디오는 내레이션 별도 녹음. 대기 구간 편집을 위해 클릭 시점마다 3초 이상 여유를 둔다.
7. 커버 이미지(선택): 켜져 있으면 여행 계획/메모판 도구에 수 초 뒤 표지 이미지가 붙는다. 장면 9에서만 필요하다.

Leave 전에 장면 9로 승인 대기 1건을 만들어 두면 요약이 풍부해진다. 보드 변화 칸은 "변화 없음"으로 나올 수 있다 |
| 9 | 여행 계획 + 커버 이미지 | 대화가 도구와 그림이 된다 | A (친구들 방) | 받는 이 `모두에게`, 입력: `이번 주말 1박2일 속초 여행 계획표 만들어 줘` | 보드에 `속초 1박2일 여행 계획표` 도구가 생기고 약 10초 뒤 도구 카드에 표지 그림이 붙음 | 25초 + 커버 10초 | 보드 쪽으로 | "계획표가 생기고, 표지 그림도 붙어요." | 없음 | 끊어 찍기·불안정. 가족 방 `이번 주말 1박2일 여행 가자`는 Agent들이 일정 충돌로 반대해 여행판이 안 만들어졌다(1/1 실패). 프롬프트 보강 후 가족 방 `이번 주말 1박2일 여행 가자` 실제 1/1 성공(약 4초, `이번 주말 1박2일 가족 여행` 도구 생성, Agent 반대 없음). 친구들 방에 다른 승인이 대기 중이면 도구를 안 만들었으니 초기화 직후에 찍는다 |

## 3. 컷 순서와 러닝타임 (목표 4분 안팎)

| 순서 | 장면 | 편집 길이 | 편집 메모 |
|---|---|---|---|
| 1 | 장면 1 오프닝 | 0:20 | 회전·확대는 원본 속도 |
| 2 | 장면 2 My Room 일정 + 2b 방들 현황 (2d 평문 컷은 대비용) | 0:30 | 대기 4~6배속, 카드가 뜨는 순간만 원속 |
| 3 | 장면 3b 투표 + 3a 사다리 + 3d 정산 | 0:45 | 대기 배속, 사다리 결과·정산 항목 추가는 원속 |

| 5 | 장면 4 가족 A2A→A2H | 0:45 | 승인 카드 클릭 후 확정 발화까지 원속 |

## 4. 알려진 화면 이슈(촬영 시 피하기)

- 입력창이 좁아져 placeholder가 2줄로 잘려 보인다(방 화면 활동 입력). 전송 전에 입력한 문장이 길면 잘림 → 촬영용 입력은 짧게.
- 승인이 많이 쌓이면 왼쪽 승인 카드 영역이 길어져 화면 아래로 밀린다. 장면 사이 승인을 처리해 정리한다.
- 시드 인물(엄마·아빠·Dana)의 Agent는 처음 말할 때 화면에 이름이 `Agent`로만 보이거나 참여자 목록에 늦게 나타날 수 있다(페이지를 새로 열면 정상). 촬영 전에 해당 방을 한 번 열었다 닫거나 새로 고침한다.
